# Anatomical source data

Revision 3 consumes only MakeHuman graphical assets under CC0-1.0. It does not copy or depend on MakeHuman's AGPL program code.

Pinned repository: https://github.com/makehumancommunity/makehuman/tree/a8bc2d54ff0ac92e78ff71431b1023eda42bf482

License: https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/LICENSE.md

The manifest pins every input Git blob and byte size. The remote builder verifies those hashes, records SHA-256 provenance, applies original posing/clothing/sampling code and emits quantized spatial data. No photographs, specific real faces, franchise assets or frame sequences are used. Only the original 0/1 renderer writes visible colour; anatomical meshes are sampling sources and depth-only occluders.
