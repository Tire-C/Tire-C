# GitHub SVG compatibility probe

This is a technical compatibility test, not the proposed artwork or profile integration.

![SVG declarative animation probe](probe.svg)

The first digit moves via SMIL; the second changes opacity. No JavaScript, remote font, or external reference is present. The cloud test observes this actual GitHub README image at multiple times and records whether it changes. A positive result proves only basic declarative animation in this context, not artistic suitability or full engine compatibility.
